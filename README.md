# 初中化学知识大全 · 一键配平

一个**单文件、离线可用**的初中化学复习网页：知识梳理 + 化学计算 + 一键配平 + 自测刷题，无需联网、无需安装任何依赖，双击即可在浏览器打开。

## ✨ 功能

- ⚖️ **一键配平**：输入任意化学方程式，自动求出最简整数系数，并逐元素验证质量守恒；离子方程式自动校验电荷守恒。
  支持括号 `Ca(OH)2`、水合物 `CuSO4·5H2O`、离子 `H+ + OH- = H2O`、全角/下标字符。
- 📚 **11 大知识板块**：化学用语与基本概念、空气与氧气、水与溶液、碳和碳的氧化物、金属与金属材料、酸/碱/盐与化肥、化学方程式与配平方法、化学计算与例题、化学实验、记忆口诀、化学与生活。
- 🧪 **50 个常见方程式库**：可逐个一键配平，也可"全部一键配平"批量核对守恒。
- 🧮 **4 类计算工具**：相对分子质量 / 元素质量分数、溶质质量分数、溶液稀释、化学方程式质量计算（与配平结果联动）。
- 🎯 **自测模式**：可自由勾选出题范围——方程式配平 / 化学用语 / 基本概念 / 化学计算 / 性质与实验；每轮 10 题，题型自动混排（单项选择、数值计算、配平判断、系数填空），答完即时判分并给出解析。
- 📕 **错题本**：答错自动收录（localStorage 存本机，不上传服务器），支持"再练这题"、按错题重练、删除与清空，导航栏显示错题数量。
- 🌙 **暗色模式**：右上角一键切换，自动记住选择；首次访问跟随系统偏好，刷新不闪屏。
- 🖼️ **网站图标**：自带 favicon（ico / SVG / PNG）、手机主屏幕图标（apple-touch-icon）与 PWA manifest，添加到主屏幕后显示蓝绿色烧瓶图标。
- 📱 响应式布局，手机端自适应；支持打印成复习资料（Ctrl + P）。

## 🚀 使用

直接用浏览器打开 `index.html` 即可。页面为纯静态单文件，所有样式与脚本内联，不请求任何外部资源。
